# JavaScript Basics Exercises

A small Express server that serves a static page (`public/index.html`) with four JavaScript exercises. Screenshots of the results are in the `Website Screenshots` folder.

## Run locally

```bash
npm install
npm start
# open http://localhost:3000
```

## What I practiced

- Basic JavaScript (DOM and logic exercises)
- Serving static files with Express
